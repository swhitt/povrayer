povrayer UI polish plan

2026-06-09 · two critique passes (visual design + power-user UX) over the live UI at 127.0.0.1:8080 · 33 findings, 27 planned

Constraint honored throughout: the existing "optical bench" design system in web/styles.css. Accent yellow only on the render action / links / focus / wordmark, square corners, the rendered image is the only shadowed/textured element, monospace only. Nothing below adds chrome; most of it removes brightness or text.

Execution waves

Wave 1, visual calm (two agents in parallel: CSS/HTML vs ui.js behavior)

Stabilize the hero plate, unify the slider language, de-dupe the example popover, fix mode-switch jank, quiet the toggle row. V1–V16 below.

Wave 2, power-user keyboard batch (ui.js agent + repl.js agent in parallel)

Comment-toggle, line duplicate/move, keyboard number stepping, Cmd+S export, Cmd+K examples, permalink full render, shortcut cheat sheet, REPL prefix history. P2–P14 below.

Wave 3, structural gaps (single agent, sequential)

Find bar + go-to-line in the editor; draggable editor/output split. The two biggest "I live in this tool" gaps.
